# Contributor conduct

We want this project to be a respectful place to ask questions, report failures, and improve software.

- Be considerate and specific. Critique ideas and code, not people.
- Welcome contributors with different backgrounds and levels of experience.
- Do not harass, threaten, discriminate, or publish another person's private information.
- Keep shared examples free of credentials and private user data.

These guidelines apply to project issues, pull requests, and other project-managed spaces. Maintainers may edit or remove harmful content, lock discussions, or restrict participation. Responses should be proportional to the behavior and allow clarification where appropriate.

Report a conduct concern through [GitHub's abuse reporting process](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam). Avoid posting sensitive details publicly. For software vulnerabilities, follow [SECURITY.md](SECURITY.md).
